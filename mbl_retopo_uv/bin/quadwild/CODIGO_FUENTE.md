# QuadWild-BiMDF: license and source code

`quadwild.exe` and `quad_from_patches.exe` in this folder are the **unmodified official binaries** of **QuadWild-BiMDF
0.0.2**, distributed under the **GNU GPL v3** (full text in [`LICENSE.txt`](LICENSE.txt), next to them).

- Original download: <https://github.com/cgg-bern/quadwild-bimdf/releases/tag/v0.0.2> (`windows-binaries.zip`).
- **Source code for this version:** <https://github.com/cgg-bern/quadwild-bimdf/tree/v0.0.2>
  (single archive: <https://github.com/cgg-bern/quadwild-bimdf/archive/refs/tags/v0.0.2.zip>).
- They were built without Blossom V, the only non-free component the project supports (the programs themselves say so:
  "Satsuma was built without blossom-V support").

MBL Retopo UV only runs these programs as separate processes (it reads and writes `.obj` files); the plugin's code is not
combined with theirs and stays under its MIT license (see `LICENSE` at the repository root).

If the link above stops working and you need the source code for this version, open an Issue at
<https://github.com/mbruguera02/MBL_Retopo_UV> and it will be provided.
